Smart Watchlist

React, Node.js, JavaScript

The problem
A long list of stocks is hard to scan. You want to know which symbols need attention right now.
What I built
A watchlist that scores every symbol from 0 to 100 using a composite Signal Score.
How it works
  • Score combines a volatility-adjusted z-score, volume anomaly and 52-week high/low crossings
  • Fan-out polling (one poll per symbol) with O(1) incremental rolling stats (EMA), keeping the poller separate from the API server
  • When the simulated data feed fails, the UI flags stale prices instead of blocking

House Price Prediction System

XGBoost, Scikit-Learn, Streamlit, Pickle

The problem
A price model is only useful if someone can try it without opening a notebook.
What I built
A Streamlit dashboard that predicts prices in real time from a model trained on 4,000+ records with 40 features.
How it works
  • EDA and feature engineering, then XGBoost hyperparameter tuning that raised R-squared from 0.31 to 0.42
  • Validated with MAE, RMSE and R-squared
